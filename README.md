
# Nature Man

*A short nature-inspired experience – made with Unity*

Hello!  
**Nature Man** is a very simple and short game (about 2 minutes long), and it’s my first experience creating a game with Unity. The main idea behind the game is to show the importance of protecting the environment in a small, friendly way. While it’s a tiny project, it’s full of motivation, learning, and love for making games.

## 🎮 How to Play

No installation needed! Just:

1. Download or clone this repository.
2. Go to the `Nature Man` folder.
3. Run the executable file (`NatureMan.exe`).
4. Enjoy the experience!

## Why I Made Nature Man

I’m just starting out in game development, and Nature Man was my practice project to learn the basics of Unity. Still, I wanted to include a simple message about environmental care—even in this small format.  
This is just the beginning, and I hope to build bigger and better projects in the future.
